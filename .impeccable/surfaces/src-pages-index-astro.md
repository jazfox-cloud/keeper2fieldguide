# Homepage surface brief

- Scope and mode: homepage for the six-page pre-launch site; Read.
- Audience and job: a search visitor needs the current release, platform, multiplayer, PC, or gameplay answer and a route to official evidence.
- Primary action: inspect the release record; secondary action: open the official game site.
- Proof: dated official-source facts, visible evidence records, and the official tinyBuild trailer with direct fallbacks.
- Constraints: independent identity; no official logo as publisher mark; no unapproved static game imagery; no invented depth; analytics off; 320px minimum; third-party video is click-to-load.
- Chosen direction: The Night Restoration Survey, using charcoal docket boards, muted violet work zones, paper-white type, and ochre registration marks.
- Memorable moment: the first viewport reads as a restoration condition report paired with an official trailer record, not a generic game-site hero.
- Unresolved: production domain registration, hosting, analytics, Search Console, and all released-build deep guides remain separately approval-gated.
